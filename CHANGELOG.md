# Changelog

## 1.0.0
- First release: streaming HTML parser, CSS cascade and layout (block, inline, flex, tables as flex rows),
  ES2017-style script engine, DOM, events and timers, `fetch`, WebAssembly backend hook, host functions
  (sync and async), per-instance privileges, fuel limits, multiple instances.
- Pluggable UI, network and file backends; a recording UI backend on the host.
